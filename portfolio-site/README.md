# Rabia Tabbassam — Portfolio Website

A responsive, dark-themed personal portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `rabia-premium-portfolio` and folder `/portfolio-site`.
4. Save and wait for GitHub Pages to publish the site.

The expected site URL is:

`https://tabbassamrabia68-code.github.io/Python-Projects-Portfolio/`

GitHub Pages must be enabled by the repository owner. The URL is not live until GitHub confirms deployment.
