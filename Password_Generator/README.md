# 🔐 Password Generator

## 📌 Project Overview

The Password Generator is a Python console application that creates strong and random passwords based on the length entered by the user.

This project is designed to improve Python programming skills while learning how to work with random values, strings, and functions.

---

## ✨ Features

- Generate secure random passwords
- User chooses the password length
- Uses uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Simple and beginner-friendly interface

---

## 🛠 Technologies Used

- Python 3
- random module
- string module
