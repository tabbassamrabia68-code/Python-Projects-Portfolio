# Employee Management System

A console-based Employee Management System built using Python.  
This project allows users to manage employee records, search employees, update information, calculate salaries, and store data using JSON.

## Features

- Add new employees
- Automatically generate Employee IDs
- View all employees
- Search employees by ID or name
- Update employee information
- Delete employees
- Calculate employee salary
- View employees by department
- Store employee data in JSON
- Input validation
- Error handling

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- CRUD Operations
- Exception Handling
- Input Validation
