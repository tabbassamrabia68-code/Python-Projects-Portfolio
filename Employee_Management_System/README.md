# 👨‍💼 Employee Management System | Python OOP Project

A Python-based Employee Management System developed using Object-Oriented Programming (OOP) and JSON file storage.

This project allows users to manage employee records, perform CRUD operations, calculate salaries, search employees, update employee information, delete records, and view employees by department.

---

## 📌 Project Overview

The Employee Management System is a console-based Python application designed to provide a simple and structured way to manage employee information.

The system allows users to add, view, search, update, and delete employee records. Employee data is stored in a JSON file so that information remains available even after the application is closed.

This project demonstrates practical application of Python programming, OOP, CRUD operations, JSON data handling, file handling, input validation, and exception handling.

## 👨‍💼 Employee Management

### ➕ Add Employee

The system allows users to add a new employee by entering:

* Name
* Age
* Phone Number
* Email
* Department
* Position
* Salary

Employee IDs are automatically generated.

Example Employee IDs:

```text
EMP1001
EMP1002
EMP1003
```

### 👥 View All Employees

Displays all registered employees and their complete information.

### 🔍 Search Employee

Employees can be searched using:

* Employee ID
* Name
* Phone Number
* Email

### ✏️ Update Employee

Existing employee information can be updated whenever required.

### 🗑️ Delete Employee

Employee records can be deleted using the Employee ID.

### 💰 Calculate Salary

The system calculates salary using the following formula:

```text
Bonus = 10% of Basic Salary
Tax = 5% of Basic Salary
Net Salary = Basic Salary + Bonus - Tax
```

### 🏢 View Department Employees

Users can view employees according to their department.

Example departments include:

* IT
* HR
* Finance
* Marketing
* Management
* Sales

---

## 💾 Data Storage

Employee information is stored in:

```text
employees.json
```

The application automatically loads existing employee records when it starts and saves changes back to the JSON file.

This provides persistent data storage between application sessions.
