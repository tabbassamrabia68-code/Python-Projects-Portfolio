# 🎮 Number Guessing Game

## 📌 Project Overview

This is a beginner-friendly Python game where the computer randomly selects a number between **1 and 100**, and the player has to guess it.

The game provides hints after each attempt until the correct number is guessed.

---

## ✨ Features

- Random number generation
- User input
- Too High / Too Low hints
- Attempt counter
- Easy-to-understand Python code

---

## 🛠 Technologies Used

- Python 3
