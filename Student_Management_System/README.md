# 🎓 Student Management System

## 📌 Project Overview

The Student Management System is a Python console-based application that allows users to manage student records efficiently. It demonstrates the use of Object-Oriented Programming (OOP) concepts and basic CRUD operations.

---

## ✨ Features

- ➕ Add Student
- 👀 View All Students
- 🔍 Search Student (Coming Soon)
- ✏️ Update Student (Coming Soon)
- 🗑️ Delete Student (Coming Soon)
- 🚪 Exit Program

---

## 🛠 Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
