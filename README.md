# 📂 Projects

## 🎮 Number Guessing Game

### 📌 Description

A simple Python console game where the computer randomly selects a number between 1 and 100, and the user has to guess it with hints.

### ✨ Features

- Random number generation
- User input
- Too High / Too Low hints
- Attempt counter
- Beginner-friendly game

### 🛠 Technologies Used

- Python 3

### ▶️ How to Run

```bash
python Number_Guessing_Game/main.py
```
